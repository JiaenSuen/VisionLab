# Module Analysis: `modules/crnn/`

The CRNN package is an integration layer between the classical image-processing front end and trainable sequence recognition. `model.py` preserves the historical convolutional and bidirectional-GRU architecture so the existing checkpoint remains loadable. `codec.py` isolates the output vocabulary and CTC greedy decoding. `preprocessing.py` makes the historical normalization and 75 x 300 input convention explicit. `inference.py` provides a high-level recognizer that accepts OpenCV images and returns both decoded text and diagnostic values such as the CTC blank ratio.

The modular separation is academically useful because it exposes domain assumptions that were previously implicit. The vocabulary is limited to digits and uppercase English letters. The source training distribution used CAPTCHA images, while the new application uses red text embedded in structured document backgrounds. The package therefore supports experiments on transfer learning without implying that the old checkpoint is already appropriate. A recognizer returning mostly blanks is now diagnosable as a model-domain issue after localization and crop generation have been independently verified.
