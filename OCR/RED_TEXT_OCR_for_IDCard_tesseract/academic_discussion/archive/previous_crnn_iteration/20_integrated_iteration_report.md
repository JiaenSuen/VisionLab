# Integrated Iteration Report: Stable Localization to Modular Recognition

## Objective

This iteration had four goals: preserve the user's modified OCR project as the reference implementation, integrate the earlier CRNN in a modular form, investigate whether clipped-looking bounding boxes should be fixed at segmentation or crop level, and create a reproducible record of the new experiments. The guiding rule was to avoid changing multiple causal variables at once because an earlier project regression had already demonstrated how easily preprocessing order changes can masquerade as algorithmic improvements or failures.

## Regression Preservation

Before introducing new behavior, `tests/baseline_regression.py` was added. It contains an explicit reference implementation of the successful `RedCharacterDetect` sequence and compares its raw mask, closed detection mask, and accepted box list against the modular pipeline. Both repository examples pass exactly: the first produces 17 boxes and the second 15. This regression check is now part of the research method, not only software testing. It freezes the known-good localization behavior while later stages are changed independently.

## Iteration A: Crop Coverage

The first new experiment separated detector geometry from recognition geometry. The tight component/group box remained unchanged, while the OCR crop was expanded. A local low-threshold red-support proxy showed that zero-padding boxes captured only 82.62% mean support and as little as 57.97% in the worst case. Fixed four-pixel and adaptive padding covered 100% of this proxy in the current examples. A separate threshold-relaxation experiment showed why this is preferable to weakening segmentation: on the larger image, extra low-contrast foreground doubled the sequence-group count from three to six.

## Iteration B: Scale-Aware Grouping

The second experiment addressed sequence fragmentation caused by an absolute gap threshold. Eight pixels was sufficient for the smaller image but produced five groups on the larger image. Ten pixels produced three coherent groups on both. The revised implementation therefore estimates an effective gap from the median component height, bounded below by the historical eight-pixel setting. This provides a simple scale normalization without changing the connected-component detector.

## Iteration C: CRNN Package Integration

The historical CAPTCHA CRNN was refactored into independent model, codec, preprocessing, and inference modules. The supplied checkpoint loads successfully on CPU and GPU-capable systems without the previous hard-coded CUDA dependency. End-to-end pipeline execution now optionally exports grouped crops and produces a CSV of predictions, blank ratios, and average maximum probabilities. The smoke test is intentionally reported as negative transfer: nearly all document crops were blank-dominated. This is useful evidence because it distinguishes successful engineering integration from unsuccessful task adaptation.

## Current Conclusion

The current bottleneck is no longer basic red localization. The strongest immediate strategy is to freeze that baseline, use scale-aware grouping, preserve extra context in OCR crops, and move experimentation to the recognition domain. Further segmentation tuning should be justified by labeled localization evidence rather than visual box tightness. The next major research asset should therefore be a labeled crop dataset generated by this fixed preprocessing pipeline, with a vocabulary that matches the intended document text.
